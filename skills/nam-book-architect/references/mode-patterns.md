# Mode patterns

Read only the selected profile section.

## Friendly explainer

Sequence from the reader's question toward a usable mental model. Chapters use
plain-language explanation, bounded analogy, worked example, misconception
repair, visual explanation, quick check, and recap. Plan frequent visuals, but
each must remove a comprehension bottleneck. Familiarity with another accessible
book is not permission to imitate its wording or trade dress.

## Textbook

Sequence foundations, mechanisms, interpretation, and application cumulatively.
Each chapter includes explicit objectives, core concepts, evidence-backed depth,
worked application, figures/tables, synthesis, references, and self-assessment.
Plan cross-chapter prerequisites and terminology deliberately so later chapters
can build rather than re-explain.

## Exam preparation

Start from the exam blueprint or a declared proxy. Allocate chapter and item
weight by importance and cognitive demand. Plan must-know concepts, high-yield
facts, discriminating comparisons, exam traps, memory aids with limitations,
practice sets, evidence-linked rationales, and rapid review. Every objective must
have assessment coverage; coverage count alone is insufficient if all items test
recall.
