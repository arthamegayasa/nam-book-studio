# Assessment blueprint and item quality

## Blueprint first

For each planned item, specify:

- `item_id` and `objective_id`
- content area and any verified exam-blueprint category
- cognitive process: recall, understand, apply, analyze, evaluate, or create as appropriate
- difficulty target and the reason it is appropriate for the audience
- item format and delivery context
- formative or summative-style purpose
- required `claim_id` and `source_id` values

Reconcile row totals, objective totals, and requested item count before drafting. Coverage should reflect instructional importance and the verified exam blueprint, not convenient facts.

## One-best-answer items

- Put the actual problem in the stem. Include only details needed to reason or to make the context realistic.
- Write the key before distractors and record the reasoning path that makes it uniquely best.
- Derive distractors from credible misconceptions, omitted steps, reversed relations, overgeneralized rules, near-neighbor diagnoses or concepts, or correct rules applied in the wrong context.
- Keep options grammatically parallel, mutually distinct, and similar in specificity and length.
- Use negative stems only when the objective genuinely requires exception finding, and make the negative visually explicit in every output format.
- Avoid trick wording, trivia unrelated to objectives, implausible distractors, gratuitous demographic details, and unqualified absolutes.
- Use “all of the above” or “none of the above” only when the format and objective make them necessary; otherwise replace them with content-bearing options.

## Rationales

The correct-answer rationale should state the deciding principle and apply it to the stem. Each distractor rationale should name the mistaken reasoning and state when that option would become correct, when useful. Rationales must teach without leaking answers into nearby unanswered items.

## Item-level review

Check factual support, unique key, objective alignment, cognitive level, accessibility, language load, option parallelism, clueing, bias, and rationale completeness. Retire an item when reasonable experts could defend multiple keys under the stated assumptions.

## Set-level review

Check blueprint reconciliation, content balance, cognitive and difficulty distribution, duplicate or near-duplicate stems, answer-position patterns, repeated cues, dependency between items, and whether one rationale reveals another answer. Report quality findings separately from the item bank.

Do not claim psychometric validity from editorial review alone. Pilot performance, item difficulty, discrimination, and fairness evidence require learner data and qualified analysis.
