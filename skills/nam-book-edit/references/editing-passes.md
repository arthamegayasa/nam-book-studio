# Editing passes

Use the pass requested by the user or project. When multiple passes are authorized, perform them in the order below so later polishing is not wasted on content that will move or disappear.

## Developmental edit

Evaluate audience fit, promise, scope, learning progression, chapter order, objective coverage, prerequisite load, pacing, redundancy, and missing material. Propose or apply structural moves with stable ID mappings. Route changes to approved scope or objectives back to architecture.

## Content and consistency edit

Check explanations, internal logic, terminology, notation, timeline, cross-chapter claims, examples, tables, captions, and references against the approved evidence and project vocabulary. Record factual queries rather than guessing. This pass does not independently approve evidence.

## Integration edit

Fit approved teaching elements, figure/table callouts, assessment links, glossary targets, and cross-references into the prose. Prevent duplicated explanation and ensure each inserted object is introduced, interpretable, and used.

## Line edit

Improve clarity, emphasis, flow, cadence, paragraph focus, transitions, concision, and voice. Preserve purposeful variation. Replace vague abstraction with specific language when the evidence supports it.

## Copyedit

Apply locale and house style for grammar, punctuation, capitalization, spelling, abbreviations, numbers, units, headings, citations, and mechanical consistency. Copyediting does not authorize changing technical values or evidence-bearing wording.

## Proof pass

Proof the typeset artifact, not only its source. Record page or location references for widows/orphans, broken headings, clipped objects, bad line breaks, cross-reference failures, caption separation, and character corruption. Route layout repairs to publishing.

## Reporting

For every pass, distinguish applied edits, author queries, evidence queries, structural proposals, and downstream invalidations. Preserve an old-to-new mapping for any moved, split, merged, or retired semantic blocks.
